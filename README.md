# IT Study Planner

Учебное веб-приложение для планирования и организации учебных задач

## Технологии
- HTML5[cite: 47]
- CSS3 (Flexbox, Grid, тайлинговый интерфейс)
- JavaScript (DOM, ES6+)
- GitHub Pages / Firebase Firestore (облачное хранение)

## Возможности
- Добавление новых учебных задач с указанием категорий и приоритетов
- Отметка выполнения задач и интерактивное перечеркивание
- Удаление ненужных записей
- Фильтрация задач (Все / Активные / Выполненные)
- Динамический расчет прогресса и статистика
- Синхронизация данных с облачной базой данных / локальным хранилищем
