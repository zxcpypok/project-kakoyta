# project-kakoyta

# IT Study Planner

Учебное веб-приложение для планирования и организации учебных задач[cite: 46, 47].

## Технологии
- HTML5[cite: 47]
- CSS3 (Flexbox, Grid, тайлинговый интерфейс)[cite: 47]
- JavaScript (DOM, ES6+)[cite: 47]
- GitHub Pages / Firebase Firestore (облачное хранение)[cite: 42, 55]

## Возможности
- Добавление новых учебных задач с указанием категорий и приоритетов[cite: 42, 47]
- Отметка выполнения задач и интерактивное перечеркивание[cite: 42, 47]
- Удаление ненужных записей[cite: 42, 47]
- Фильтрация задач (Все / Активные / Выполненные)[cite: 42, 47]
- Динамический расчет прогресса и статистика[cite: 26, 42]
- Синхронизация данных с облачной базой данных / локальным хранилищем[cite: 17, 18, 42, 47]
